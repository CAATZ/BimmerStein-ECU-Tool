# MS42 and MS43 support

Beta 19 supports MS42 and MS43 through the same Flash, Diagnostics, Live Data,
Adaptations, Bins and ECU Config workflows used by the rest of the application.
Available operations follow the detected firmware and hardware.

## Firmware and files

| ECU | Application revisions | Full ROM | Calibration |
| --- | --- | --- | --- |
| MS42 | 0110C6, 0110C7, 0110CA | 512 KiB | 32 KiB |
| MS43 | 430037, 430055, 430064, 430065, 430066, 430069, 43X001 | 512 KiB | 64 KiB |

Application support does not imply that every boot-code variant supports RAM
transfer. The app checks the live boot/service code. Recognized boot variants
are based on MS42 0110C6 and MS43 430055/430069; other compatible applications
may retain those boots. An unknown boot uses stock DS2 where available.
No individual ECU boot-mode backup is needed for normal RAM entry.

MS42 and MS43 files are separate families. Do not use an MS41 image or combine
a calibration with an unrelated full image. Some MS43 calibration checks need
matching program context; a partial file alone cannot establish that check.

## Reads, writes and recovery

Automatic mode uses a temporary RAM agent when compatible. Standard fast rates
are **166,667 baud for MS42** and **187,500 baud for MS43**. The saved
**125,000-baud compatibility** option applies to RAM reads and writes. Stock
diagnostics use 9,600 baud. **Force DS2 (slow)** selects the stock route.

The RAM agent temporarily suspends normal ECU operation and restarts it when
finished. Keep the engine stopped. It is not a persistent firmware installation.

Before erase, a failed fast entry may fall back only after a safe diagnostic
state is confirmed. Once programming may have started, keep the app open,
ignition on and the adapter connected. Use the offered retry for the retained
operation; do not reconnect or switch routes independently.

Full writes normally preserve boot code and protected identity. **Include boot
code** requires the RAM agent, a compatible target and typed **WRITE BOOT**
confirmation. Boot sectors receive required verification. The optional identity
graft preserves live VIN/AIF history, ISN/pairing records and ECU identifiers.
Separate retained flash and EEPROM storage are not overwritten by this option.
Stock DS2 does not offer boot writes.

**Back up before write** and **Verify after write** follow your choices.
Required ECU-side finalization remains part of every successful write. Follow
the displayed ignition-cycle instructions when programming finishes.

## ECU information and diagnostics

ECU Info shows software and hardware identification, VIN, programming history,
ECU number and ISN where available. Values unavailable from the ECU are labelled
accordingly; a missing value is not proof that the ECU is unpaired.

Supply after the main relay and ignition supply (KL15) are separate readings.
A bench connection may not energize every supply path. Do not treat one field
as the other or assume that either replaces a measured supply check.

Diagnostics provides English fault descriptions, supported freeze-frame details,
actuator tests and passive cylinder roughness monitoring. Correct the cause of
a fault before clearing it: an active fault may return immediately. A successful
clear request and a failed follow-up read are reported separately; stale results
are removed and only the read is retried.

Live Data includes mapped engine channels, CSV recording, graphs and instruments.
Adaptations reads supported learned values and offers the available resets.
The empty **Not read** view before the first read is normal.

## Identity and storage

The ECU Data tab separates two tasks:

- **Read Identity / History** reads identification and programming records through
  normal diagnostics. It does not read the whole storage memory.
- **Read Flash Journal**, **Read EEPROM** or **Read Flash Banks** reads the selected
  storage through its RAM agent. Flash reads can fall back to stock DS2; the
  separate MS43 EEPROM has no stock DS2 read fallback.

| Memory | Meaning |
| --- | --- |
| MS42 flash journal, 16 KiB | Retained learned values and diagnostic records |
| MS43 EEPROM, 2 KiB | Separate serial EEPROM, saved low byte first |
| MS43 raw flash banks, 16 KiB | Separate flash storage; its operational use is not established |

**Inspect / Edit Backup** shows decoded fields, checks and raw bytes. Only fields
with established formats and restore behavior are editable. Matching calibration
is needed for calibration-dependent values and table axes. Unknown values remain
raw or read-only. An all-FF flash-bank backup is not an EEPROM capture.

Undo/redo, comparison and explicit check repair affect the loaded backup only.
Save a copy to keep those changes. **Restore Loaded Backup** is a separate
confirmed write with readback; use **Retry Storage Restore** if the app retains
an interrupted operation. Neither ordinary flashing nor identity grafting runs
a storage restore.

VIN editing preserves the remaining identity data and handles full or interrupted
programming history. Virginizing clears supported ISN/pairing records; clearing
VIN and AIF programming history is optional. It does not perform EWS alignment.
43X001 has different pairing behavior and is not offered stock virginizing.

## Configuration and remaining limits

ECU Config offers only the controls established for the selected revision.
Some controls affect calibration; program controls require a compatible full
image. Writes use the shared flash workflow, including boot confirmation where
applicable. Immobilizer and checksum options are revision-specific; their presence
does not make other revisions compatible.

**Coding and guided transmission conversion are HIGHLY EXPERIMENTAL and are
not recommended until further testing.** Supported E46 and E39 conversions
require exact donor and module matches. Complete E53/Z3 conversions and other
unlisted donor combinations remain unavailable.

Global VANOS, complete knock-detection disabling, IACV conversion and a complete
ASC equivalent remain unresolved. Octane-adaptation learning is a separate
control and does not disable knock protection. Unmapped storage and MS43
synchronization fields remain read-only. MS41 Soft-BSL, hardware BSL and the
MS41 Patches catalog are not offered for MS42/MS43.

Offline checks cover the supported firmware contracts and recovery paths. They
do not establish physical behavior on every ECU, module or vehicle.
