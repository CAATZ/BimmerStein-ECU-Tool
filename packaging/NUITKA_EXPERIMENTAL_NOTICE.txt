BimmerStein ECU Tool - Experimental Nuitka Build
=================================================

This package was compiled with the experimental Nuitka release backend.

The regular PyInstaller installer is the recommended Windows package. The
Nuitka installer is supplied as a second option for compatibility testing and
may behave differently on some systems. Both packages are built from the same
source and contain the same ECU programming logic.

Before connecting to an ECU, confirm that the application starts normally and
that the intended FTDI driver and adapter are detected. Keep a verified ECU
backup and an appropriate recovery method available for every write operation.

Please report Nuitka-specific startup or packaging issues separately and state
that the experimental Nuitka build was used.
